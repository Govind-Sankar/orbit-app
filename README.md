# Orbit

Orbit is a third-party app built for the VTOPCC website.

This project is not affiliated with, endorsed by, or officially connected to VIT Chennai. It is an independent app created by a student of VIT Chennai for personal and community use.

The app is not an official VIT Chennai product or service, and any data or functionality it provides is based on unofficial access to the VTOPCC website.

## Purpose

This app is intended to make it easier to access VTOPCC-related information in a more convenient way for users.
